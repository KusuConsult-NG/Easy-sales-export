# API Documentation

## Overview

Easy Sales Export Platform provides Server Actions (Next.js 16) for all backend operations. This document covers key API endpoints and integration patterns.

---

## Authentication

All authenticated requests require a valid NextAuth session.

### Session Management

```typescript
import { getServerSession } from "next-auth";
import { authOptions } from "@/lib/auth";

const session = await getServerSession(authOptions);
if (!session?.user?.email) {
  return { success: false, error: "Authentication required" };
}
```

## Marketplace API

### Products

#### Get All Products
```typescript
import { getProductsAction } from "@/app/actions/marketplace";

const result = await getProductsAction({
  category?: string;
  searchQuery?: string;
  minPrice?: number;
  maxPrice?: number;
  limit?: number;
});

// Response
{
  success: boolean;
  products: Product[];
  error?: string;
}
```

#### Get Product by ID
```typescript
import { getProductByIdAction } from "@/app/actions/marketplace";

const result = await getProductByIdAction(productId: string);

// Response
{
  success: boolean;
  product: Product | null;
  error?: string;
}
```

#### Create Product (Vendor Only)
```typescript
import { createProductAction } from "@/app/actions/marketplace";

const result = await createProductAction({
  name: string;
  description: string;
  price: number;
  category: string;
  imageUrl: string;
  stock: number;
});
```

### Orders

#### Create Order
```typescript
import { createOrderAction } from "@/app/actions/orders";

const result = await createOrderAction({
  items: CartItem[];
  paymentMethod: "paystack" | "bank_transfer";
  shippingAddress: Address;
});

// Response
{
 success: boolean;
  order: Order;
  paymentUrl?: string; // For Paystack
}
```

#### Get User Orders
```typescript
import { getUserOrdersAction } from "@/app/actions/orders";

const result = await getUserOrdersAction();
```

### Disputes

#### Create Dispute
```typescript
import { createDisputeAction } from "@/app/actions/disputes";

const result = await createDisputeAction({
  orderId: string;
  reason: "not_received" | "wrong_item" | "damaged" | "fake_product" | "other";
  description: string;
  evidenceUrls?: string[];
});
```

### Properties

```typescript

  title: string;
```

## Cooperatives API

### Join Cooperative

**Not currently available.** This section used to show a call to
`joinCooperativeAction`, and it was wrong three ways: it imported from a module
path that does not resolve (the actions live under `cooperative`, singular), the
argument shape shown was not the one the action takes, and the action refuses
unless a document already exists in the `cooperatives` collection — which
nothing in the platform creates.

The platform runs one cooperative, and members are registered through
`/cooperatives/register` rather than by joining one by id. See
`src/lib/cooperative-admin-scope.ts` (#248) for the measurement.

### Apply for Loan
```typescript
import { applyForLoanAction } from "@/app/actions/cooperative";

const result = await applyForLoanAction({
  cooperativeId: string;
  amount: number;
  purpose: string;
  repaymentPeriod: number; // months
});
```

## Error Handling

All Server Actions return a consistent response format:

```typescript
type ActionResponse<T> = {
  success: boolean;
  data?: T;
  error?: string;
};
```

### Common Error Codes

| Error | Description |
|-------|------------|
| `Authentication required` | User not logged in |
| `Permission denied` | Insufficient privileges |
| `Resource not found` | ID not found in database |
| `Validation error` | Invalid input data |
| `Payment failed` | Paystack transaction failed |

## Rate Limiting

Currently implemented at Vercel edge level:
- **Public endpoints**: 100 requests/minute
- **Authenticated endpoints**: 300 requests/minute
- **Admin endpoints**: 1000 requests/minute
